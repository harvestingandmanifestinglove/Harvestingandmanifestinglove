# Harvesting & Manifesting Love

An 18+ dating-community front-end preview.

## Files
- index.html — website structure
- styles.css — design and responsive layout
- script.js — buttons and demo interactions
- vercel.json — Vercel configuration

## Important
This version is a front-end preview. It does not store member accounts, messages, or payments.
Before accepting real members or R50 payments, connect secure authentication, a database,
moderation/reporting, terms/privacy pages, HTTPS/security controls, and a real South African
payment provider.
